THE TAKEAWAY

“Important” needs a second word.

Spider-Man leads incoming links; Betsy Braddock leads outgoing links. Betweenness asks about shortest-path brokerage. Clustering asks how connected an article’s neighbours are to each other. A single leaderboard hides these different questions.

The greedy five-card reference covers 184 / 303 articles. It is a reproducible baseline, not a proven optimum. Covering all 303 with five cards is impossible: each of the 17 isolates would require its own card.

Behind the cabinet

What the data means

303 article entries and 1,784 directed links from the course’s frozen 26 August 2026 snapshot. A link means one article links to another within this roster. It does not measure friendship, hero strength, popularity or the whole Marvel universe.

Download the snapshot and metrics (JSON)

Limits of the experiment

All rankings are properties of this article graph. They do not rank character strength or causal influence. Shortest paths are a modelling choice. This is a free-play experiment, not a course post.

Methods and reproducibility

Degrees use the original directed graph or its simple undirected collapse, as labelled. Betweenness is exact and normalized over all 303 nodes, computed with NetworkX 3.6.1. Local clustering is zero for degree below two. Coverage is the union of closed one-hop undirected neighbourhoods. The reference draft repeatedly chooses the card adding most uncovered nodes, with deterministic ID tie-breaking.

Analysis and source code on GitHub. All experiments run locally in your browser; the frozen data is never edited.
