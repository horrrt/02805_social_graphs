Take a network apart, one week at a time

Eight course weeks. Four on network structure, four on language.

Each post asks one question about a real network, gives you one thing to try, then shows the result and the evidence behind it. We started on 303 Marvel Wikipedia articles, moved to migration between countries, and then to the firms that file for H-1B workers in the United States. No network-science background needed: every post explains its data and terms on its own.

Sources and methods

Methods and reproducibility

Every number on the site comes from a script in analysis/ and reaches the page as JSON, so a rerun reproduces the post. Structural claims are held to a null model that keeps what the claim does not test, and stochastic methods run with fixed seeds, many times. Interactive parts run in your browser; the data is never edited.

AI use and authorship

Built with AI assistance for interface design, programming, explanation drafts and test construction. Metrics come from the source data and reproducible analysis; the games and metaphors are our presentation choices. Numerical checks compare independent Python and browser implementations.
